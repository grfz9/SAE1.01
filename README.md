# MiniTok 🎵

Clone simplifié de TikTok en HTML/CSS/JavaScript (sans dépendance).

## Lancer
Ouvre `index.html` dans un navigateur, ou : `python3 -m http.server` puis http://localhost:8000

## Fonctionnalités
- Fil vertical plein écran avec défilement « snap » (molette, swipe, flèches ↑/↓)
- Lecture auto de la vidéo visible, barre de progression
- Tap = son / pause, double-tap = ❤ avec animation
- Likes, abonnements, partage (copie du lien), commentaires
- Onglets « Pour toi » / « Abonnements »
- Publication d'une vidéo depuis ton appareil (bouton ＋)
- Page profil ; likes/commentaires/abonnements sauvegardés en localStorage
