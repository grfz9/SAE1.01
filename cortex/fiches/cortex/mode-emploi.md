# Mode d'emploi

**Parle normalement à Claude** : il range tout seul ce qui mérite d'être retenu.

Commandes utiles :
- `/fiche <texte>` : range une info précise.
- `/ranger` : relit la conversation et range tout ce qui compte.
- `/relier` : ajoute les liens qui manquent entre les fiches.
- `/bilan` : fait le point (orphelines, doublons, infos obsolètes).
- `/carte` : ouvre la carte de ton cerveau.

Bons réflexes :
- Commence par remplir [[moi]] et [[objectifs]].
- Une fiche = une idée. Les liens comptent autant que le contenu.
